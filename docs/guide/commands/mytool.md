## 호출

## 요약 (mytool-help)

- Usage: mytool-help [section|--list|--all]
- sections
    - tools: list all .sh files in shell-common/tools/custom/
    - usage: how to run custom tools
    - details: mytool-help <section>  (example: mytool-help tools)
