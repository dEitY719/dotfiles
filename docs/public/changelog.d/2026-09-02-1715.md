- 변경: **`claude/settings.json`에 `CLAUDE_CODE_SESSIONEND_HOOKS_TIMEOUT_MS=10000` 추가 (외부/공용 PC 한정, #1715)** — agentmemory 플러그인의 SessionEnd 훅(`session-end.mjs`)은 REST 요청을 fire-and-forget으로 발사한 뒤 1.5초 failsafe로 강제 종료해 실측 최악 케이스가 ~4.5초(기존에 알려졌던 "최대 30초"는 fetch abort 시한일 뿐 프로세스 수명과 무관)인데, 이보다 짧은 SessionEnd 훅 예산에서 `/exit` 시 `Hook cancelled` 에러가 노출되던 문제를 여유를 둬 완화. 사내 PC는 `gateway-cli`가 live `env.*`를 소유해 이 SSOT 변경이 적용되지 않는다. `docs/guide/playbooks/agentmemory/README.md`에도 실측 근거와 사내 PC 제외 캐비어트 추가.
