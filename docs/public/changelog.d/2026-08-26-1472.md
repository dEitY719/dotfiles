- 변경: **`aicron` 추가 — 매니페스트(`shell-common/tools/custom/cron-jobs.json`) 기반 cron 잡 관리 CLI (`list`/`add`/`remove`/`pause`/`resume`/`status`/`run`/`doctor`).** 잡의 스케줄·인자·환경변수·로그 경로가 한 사람의 crontab 에만 있던 상태를 버전 관리되는 JSON 매니페스트로 옮겼다. `add`/`remove` 는 `# BEGIN aicron:<job>` ~ `# END aicron:<job>` 마커 블록만 편집하므로 손으로 쓴 나머지 crontab 줄은 바이트 단위로 보존되고, "설치됐는가"의 SSOT 는 상태 파일이 아니라 crontab 자신이다(D-3). `run` 은 cron 과 동일한 1회 실행을 수행하면서 일시정지(`pause`)·중복 실행(per-job flock)·로그 로테이션(7 MiB, 1세대)·실행 결과 기록(`last_run`/`last_exit`/`last_duration_sec`)을 처리하고 잡의 종료 코드를 그대로 전파한다 — 건너뛴 경우만 0 이다(cron 이 non-zero 에 메일을 보내므로). 매니페스트 값은 `eval` 을 거치지 않고 `$HOME` 만 문자열 치환되며, `env NAME=VALUE` 인자로 잡에 전달된다 (#1472)
