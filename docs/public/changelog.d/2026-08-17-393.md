- 변경: **프로젝트 보드 `Approved` 컬럼의 소유권을 `/gh-pr-reply` 에서 `/gh-pr-approve` 로 이관했다 (#1350). `/gh-pr-reply` 의 Step 8 "Solo-Repo Auto-Approve" 와 `references/auto-approve.md` 를 제거했다 — `agy`/`codex` 리뷰와 pr-reply 답변은 모두 `COMMENTED` 라 `reviewDecision` 을 바꾸지 않는데, G4 가드가 빈 `reviewDecision` 을 통과시켜 BLOCKING 판정 PR 까지 `Approved` 로 올려보냈다 (PR #1349). 이제 카드는 사람이 `/gh-pr-approve` 를 명시적으로 호출할 때만 이동한다: 실제 `--approve` 경로(4a/4b)와 self-PR `--self-record` 경로(자기 PR 은 `reviewDecision` 이 영원히 비어 있으므로 `_GH_PROJECT_STATUS_GUARD_APPROVED_BYPASS=1` 접두 형식으로 1회 호출만 bypass). 승격 가드는 `--only-from "Backlog,In progress,In review"` 로, `.github/workflows/project-board-sync.yml` 의 approve 핸들러와 동일한 시작 컬럼 화이트리스트를 쓴다 (PR #1352 리뷰 반영) — `Done` 만 배제해 머지된 카드의 역행을 막고, `Changes requested` 로 `In progress` 에 떨어진 카드가 수동 복귀 없이도 승격될 수 있게 한다. `shell-common/functions/gh_project_status.sh` 의 #393 fail-closed 가드는 다른 호출자 보호를 위해 그대로 둔다. 부수적으로 `GH_PR_REPLY_AUTO_APPROVE_REPOS` 환경변수와 `gh:kanban-bootstrap` 의 `~/.zshrc.local` 자동 배선(및 `--no-auto-approve-env` 플래그)이 사라졌다. **조치 필요**: `claude/settings.json` 은 SSOT 원본이며 각 계정 설정 디렉터리로 심링크가 아니라 *복사*되므로, 이미 배포된 사본에서 해당 키가 자동으로 사라지지 않는다 — `./claude/setup.sh` 를 재실행하거나 사본과 `~/.zshrc.local` 에서 `GH_PR_REPLY_AUTO_APPROVE_REPOS` 를 직접 지운다 (남아 있어도 이제 아무도 읽지 않으므로 무해하다)**
