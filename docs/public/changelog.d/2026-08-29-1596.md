- 변경: **issue-watcher 의 "running now" 신호가 pane 의 `agent_status` 를 함께 본다 — `agent_status` 가 `idle`/`done` 이면서 해당 이슈가 GitHub 에서 이미 CLOSED 인 pane 은 live 집합에서 제외된다. 지금까지는 pane 의 `cwd` 가 이슈 워크트리 안에 있기만 하면 무조건 live 로 셌기 때문에, 머지 후 닫히지 못한 herdr 탭(좀비 탭)이 repo 당 동시 실행 상한(`_IW_MAX_PER_REPO`, 기본 7)의 슬롯을 영구히 점유해 해당 repo 의 신규 이슈 dispatch 가 조용히 멈추고, 그 워크트리도 영영 회수되지 않았다. 두 조건을 모두 요구하는 이유는 각각이 정상 중간 상태이기 때문이다 — 에이전트는 툴 호출 사이에 잠깐 `idle` 이 되고, 이슈는 세션이 머지 검증 중일 때 이미 닫혀 있을 수 있다. `idle`/`done` 이 아닌 상태(미지의 상태 포함)와 이슈 상태 조회 실패는 모두 "아직 살아 있음" 쪽으로 판정한다. `gh issue view` 왕복은 멈춘 pane 에 대해서만 지불한다.
