- 변경: **statusline 이 현재 effort 레벨을 모델 뒤에 달 위상 글리프로 표시 — `🌑 low` / `🌒 medium` / `🌓 high` / `🌔 xhigh` / `🌕 max`. Claude Code 는 statusline stdin JSON 에 `.effort.level` 을 실어 보내되 모델이 effort 를 지원할 때만 그 키를 넣는다(`claude-3-*`, `opus-4-0/4-1`, `sonnet-4-0/4-5` 등은 없음) — 키가 없으면 세그먼트와 구분자가 함께 빠져 라인이 종전과 완전히 동일하다. 매핑에 없는 값은 숨기지 않고 원문 텍스트로 보여 향후 신규 레벨이 조용히 사라지지 않게 한다. `ultracode` 는 표시하지 않는다: 레벨이 아니라 세션 모드이고 켜지면 effortValue 가 `xhigh` 로 강제되어 페이로드만으로는 둘을 구분할 수 없다 (#1302)**
- 변경: **statusline 의 jq→bash 필드 리더가 빈 필드를 잃던 버그 수정 — `@tsv` + `IFS=$'\t' read` 조합은 탭이 IFS *공백류* 문자라서 연속된 탭을 하나로 합치고 선행 탭을 버린다. 그래서 중간 필드가 비면 뒤의 값들이 통째로 왼쪽으로 밀렸다. 비는 필드(`used_pct`/`total_tokens`)가 목록 맨 끝에 몰려 있던 동안에는 후행 절삭이 무해해 드러나지 않았지만, `.effort.level` 을 6번째로 추가하면서 그 자리가 중간이 되어 실제 버그가 됐다(예: `{"cwd":"/tmp","effort":{"level":"max"}}` 가 `🧠 max` 로 모델 슬롯을 오염시키고 effort 는 사라짐). NUL 구분 출력 + `mapfile -d '' -t` 로 교체해 위치를 보존한다. 개행 구분으로 바꾸는 것만으로는 부족하다 — 값 자체가 구분자 바이트를 담으면 똑같이 뒤 필드가 밀리기 때문으로, 탭은 `.model.display_name` 에서, 개행은 `.cwd` 에서 터진다(둘 다 회귀 테스트로 고정). NUL 은 bash 변수가 담을 수 없는 유일한 바이트라 어떤 값도 위조할 수 없다. jq fork 는 여전히 1회이며, here-string 으로 `echo` 파이프의 두 번째 fork 까지 없애 렌더는 오히려 소폭 빨라졌다 (#1302)**
