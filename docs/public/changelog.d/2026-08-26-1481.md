- 변경: **`aicron help` 표에서 `status <job>` 행 정렬이 밀리던 문제를 고쳤다 (#1481).** `ux_table_row` 의 라벨 칸은 `%-20s` 고정폭이라 20자를 넘는 라벨은 잘리지 않고 뒤따르는 구분자(`:`)를 한 칸 밀어냈는데, 대괄호가 붙은 `status <job> [--json]` 이 21자로 유일하게 이 폭을 넘었다. `ux_lib.sh` 의 고정폭 자체를 넓히면 이미 정렬된 100여 개 호출부가 전부 밀리고 55자짜리 라벨도 여전히 넘치므로 수정 범위를 `aicron.sh:102` 라벨 하나로 좁혔다. 첫 시도는 `--json` 을 설명문으로 옮기는 것이었지만, 이후 PR #1485 리뷰(agy·codex 모두 독립적으로 지적)에서 문법 열에 있어야 실제 사용 형태를 그대로 복사할 수 있다는 discoverability 우려가 나왔다 — 다시 보니 대괄호만 빼면 `status <job> --json` 이 19자로 20자 폭 안에 들어가므로, 최종 수정은 대괄호를 제거해 플래그를 문법 열에 그대로 남기는 쪽으로 바뀌었다. `ux_table_row` 를 쓰는 다른 20자 초과 라벨(`ai_tools_help.sh` 등)은 이번 수정 범위 밖이며 후속 이슈로 남는다.
