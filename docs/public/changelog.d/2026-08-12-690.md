- 변경: **`/devx:md-to-scrolldeck` 스킬 신설 — Markdown 문서 1개를 세로 scroll-snap 프레젠테이션 덱(HTML 단일 파일)으로 변환한다. 리더 보고용 산출물이 대상이며 상단 progress bar · phase 라벨과 `01 / NN` 카운터를 단 고정 헤더 · 우측 dot rail · `IntersectionObserver` 활성 슬라이드 추적 · 방향키 이동 · 슬라이드별 scroll cue · 인쇄 시 snap 해제 후 전 슬라이드 페이지 분할을 갖춘다. 핵심은 마크업이 아니라 **편집적 압축**이다 — 제목 1:1 매핑은 목차를 만들 뿐이라, HTML 을 쓰기 전에 nav-dot 개요(슬라이드 id · 라벨 · archetype · phase · 출처 라인 범위 + 잘라낸 것)를 먼저 출력해 사람이 개입할 지점을 만든다(레퍼런스 문서 기준 제목 약 39개 → 슬라이드 15개). `devx:visualize` 와 의도적으로 갈라지는 두 지점: (1) 햄버거 메뉴 `.viz-menu` · 테마 토글 · PNG 내보내기를 넣지 않는다 — 이 포맷은 단일 라이트 페이퍼 테마이고 다크 슬라이드는 사용자 설정이 아니라 편집적 대비다, (2) 웹폰트를 base64 로 임베드하지 않고 CDN 링크를 쓴다 — 레퍼런스 덱에서 폰트 한 줄이 2,743,627자(파일 2.86MB 의 96%)였고 이는 사내 Bedrock 의 `Truncated event message received` 를 그대로 부르는 형태다(#690). 두 divergence 는 `references/checklist.md` 가 "있으면 실패" 항목으로 고정해 devx:visualize 를 그대로 복사하다 되돌아가는 것을 막는다. 출력 경로는 입력 md 와 같은 디렉터리·같은 basename 의 `.html`, 전달은 단일 `Write` + `xdg-open` + `file://` URL 만이고 HTML 본문은 채팅에 절대 출력하지 않는다. 옵션: `--out <path>` · `--slides <n>` · `--outline-only` · `--lang <code>` · `--offline-font` · `--no-open` · `-h`/`--help`/`help`**
