- 변경: **`devx:pr-verify-merged` 의 차별 기능 2종 — (1) 환경 변이 재실행: 같은 검증을 `PATH=/usr/bin:/bin` 로 한 번 더 돌려 사용자 셸의 도구 치환을 배제한다(실측: `grep` 이 GNU grep 3.11 이 아니라 ugrep 7.5.0 이라 CRLF 처리가 기계마다 갈렸다). locale · 셸 · 줄 끝 축은 diff 에서 유도한 후보로 리포트에만 적고 `--matrix full`/`--env` 일 때만 실행하며, 축 1개 실패는 그 축만 `unverified` 로 전체 정지가 아니다.
