- 변경: **운영자 조치: 이 변경을 pull 한 뒤 `aicron` 잡을 다시 설치할 필요는 없다. crontab 줄은 `<schedule> <aicron.sh> run <job>` 이고 `env`·`args` 는 매 tick `aicron run` 이 매니페스트에서 다시 읽으므로, 계정 변경은 다음 tick 부터 저절로 적용된다. `aicron remove <job> && aicron add <job>` 가 필요한 것은 잡의 `schedule` 이나 `script` 경로가 바뀔 때뿐이다. 확인은 `aicron run issue-watcher` 후 `herdr agent read` 로 팬이 `W1` 로 떴는지 보면 된다.
