- 변경: **`shell-common/tools/custom/issue_watcher_cron.sh` 의 dispatcher 프롬프트 `_IW_PROMPT` 가 `@issue-watcher:dispatcher 실행` 에서 `issue-watcher:dispatcher 를 Agent 도구로 실행해` 로 바뀌었다 — 이 문자열은 herdr pane 의 claude 세션에 그대로 전달되는데, `@<name>` 만으로는 받는 세션이 Skill 인지 Agent 인지 헷갈려 매 tick 마다 `Skill(issue-watcher:dispatcher)` 를 먼저 시도해 실패한 뒤에야 Agent 로 재시도했다. 결과적으로는 매번 성공했지만 무인 cron 경로가 모델의 self-correction 에 의존하는 상태였다. 호출할 도구를 문장으로 명시해 그 오인 경로를 없앴다 — `herdr agent prompt` 는 자유 문자열만 싣는 채널이라 구조적 도구 호출은 애초에 불가능하고, 이 변경이 없애는 것은 "모델이 추론한다" 자체가 아니라 `@`+콜론 네임스페이스가 Skill 이름으로 보이던 특정 실패 트리거다. 같은 이유로 세션 언어 설정에 덜 흔들리도록 영어 지시문(`run the issue-watcher:dispatcher agent via the Agent tool`)을 병기했다. `@` 접두사가 다시 붙으면 실패하는 bats 회귀 가드를 함께 넣었다. 수신 세션이 실제로 첫 시도에 Agent 도구를 타는지는 스텁 기반 bats 로 검증할 수 없어 실제 cron tick 수동 확인 대상으로 남는다 (#1394)**
