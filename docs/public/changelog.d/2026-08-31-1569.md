- 변경: **"이 워크트리에 herdr 에이전트가 앉아 있는가" 판정을 `shell-common/functions/herdr_agent_lookup.sh` 하나로 통합했다. 종전에는 같은 질문을 네 곳(`issue_watcher_cron.sh` 의 `_iw_live_agents`, `gh:pr-post-merge-verify` 의 `pmv_tab_for_cwd`, `gh:pr-merge` 의 herdr 유휴탭 힌트, `gh:pr-merge-train` 의 구현탭 닫기)이 각자 손으로 베낀 jq 로 답했고, 이미 세 갈래로 갈라져 있었다 — 가장 최근 사본인 `gh:pr-merge` 힌트만 `.cwd` 문자열 완전일치라, 워크트리 하위 디렉터리로 `cd` 한 세션과 심링크로 도달한 워크트리를 통째로 놓쳤다. 이제 네 곳 모두 같은 술어를 쓴다: `.cwd` 와 `.foreground_cwd` 를 **둘 다**, 심링크를 푼 **물리 경로**에 대해, `<path>` 자신이거나 `<path>/` 로 시작하는 **경계(boundary) 매칭** — 그래서 `/work/repo-1` 이 `/work/repo-11` 을 삼키지 않고, 빈 경로는 아무것도 매칭하지 않는다. 반환은 rc 0(찾음, tab_id 를 stdout 으로) / rc 1(herdr 에 아예 물어보지 못함) / rc 3(herdr 이 답했고 그 경로엔 아무것도 없음) 3분기를 유지한다 — herdr 이 침묵한 것을 "도는 게 없음"으로 읽는 것은 issue-watcher 의 동시성 캡을 herdr 이 아플 때 정확히 풀어버리는 사고이기 때문이다. `_iw_live_agents` 는 tick 당 `herdr agent list` 를 여전히 **1회만** 호출한다(배치용 `herdr_agent_live_cwds` + 로컬 매칭 `herdr_agent_cwds_match`). 사용자 눈에 보이는 유일한 동작 변화는 `gh:pr-merge` 의 유휴탭 힌트가 넓어진 것 — 하위 디렉터리에 있던 세션·`foreground_cwd` 로만 잡히는 세션·심링크 워크트리도 이제 `[INFO]` 한 줄로 알려준다. 이 힌트는 여전히 읽기 전용이고(NF-2) 탭을 닫거나 무엇도 변경하지 않는다.
